# My Progress

This is a template. Copy it to `course/MY-PROGRESS.md` before you tick anything:

```bash
cp course/PROGRESS.md course/MY-PROGRESS.md
```

`MY-PROGRESS.md` is ignored by git, so your progress never conflicts with updates you pull from the repository.

For each lesson, tick **Done** when all of its exercise tests pass (`npm run course:progress` shows this). Then answer the lesson's self-check questions again, without looking, after 1 day, 3 days and 1 week. Write the review dates next to the boxes if that helps.
